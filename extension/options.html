STAR SHELF / SETTINGS

A small, private archive
for good ideas.

Star Shelf reads your GitHub stars only when you ask it to sync. Categorization happens locally in your browser.

01

Connect GitHub

Use a fine-grained personal access token with read-only access to your profile’s starred repositories. Classic tokens need no extra scopes for public stars; private repository stars require appropriate repository read access.

Stored only in Chrome’s local extension storage. It is sent only to api.github.com for sync requests.

02

Your data stays with you

  • No analytics, ads, or remote Star Shelf service.
  • Your GitHub token and imported repository metadata stay in this Chrome profile.
  • The extension requests access only to GitHub pages and the GitHub REST API.

This keeps your saved token. Remove the token above and save to fully disconnect GitHub.

Star Shelf is intentionally local-first.
